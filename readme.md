# SalabimPtk - Production Simulation

A production simulation project built on [salabim](https://github.com/salabim/salabim), a discrete event simulation library for Python.

## About

This project uses salabim to model and simulate production systems. The goal is to analyze production workflows, identify bottlenecks, and optimize throughput in manufacturing and industrial processes.

## Getting Started

### Prerequisites

- Python 3.8+
- salabim

### Installation

```bash
pip install salabim
```
